커머스개발 : 주문 취소 정책

Created by 박성민, last modified by 박성민 on 2021-03-17

이 문서는 주문팀에서 관리합니다. 정책 변경 시 반드시 이 페이지를 갱신해 주세요.

1. 개요

셀플로우 주문 취소 처리에 대한 정책과 시스템 동작을 정리한 문서입니다. 고객 취소, 파트너 취소, 시스템 자동 취소를 모두 포함합니다.

2. 취소 사유 코드

코드사유비고
01파트너 귀책 (재고 부족, 출고 지연)파트너 부담
02시스템 오류셀플로우 부담
03고객 변심배송 시작 전만 가능
04배송 실패 (주소 불명, 수취 거부)물류팀 확인 후 처리

3. 취소 가능 시점

주문 상태에 따라 취소 가능 여부가 달라집니다.

주문 상태취소 가능처리 방식
결제완료O즉시 취소, 전액 환불
상품준비중O즉시 취소, 전액 환불
배송중△물류팀 확인 필요
배송완료△반품 프로세스로 전환
정산완료X취소 불가

4. 정산 완료 주문에 대하여

정산이 완료된 주문은 취소할 수 없습니다.

정산 배치가 실행되어 파트너에게 정산금이 지급된 주문은 시스템에서 취소가 차단됩니다. order-service의 취소 API는 주문의 정산 상태를 확인하며, SETTLEMENT_DTL에 해당 주문이 포함되어 있는 경우 409 Conflict를 반환합니다.

고객이 정산 완료 후 취소를 요청하는 경우, CS팀은 반품 프로세스를 안내해야 합니다. 취소가 아닌 반품으로 처리되며, 반품 승인 후 별도의 환불 절차를 거칩니다.

정산 배치는 매일 새벽 2시에 실행됩니다. 따라서 주문 당일 자정까지는 취소가 자유롭게 가능합니다.

5. 재고 복원

취소 시 재고 복원은 inventory-api가 처리합니다. 취소 사유 코드에 따라 복원 여부가 달라지므로 재고팀과 협의가 필요합니다.

6. 관련 문서

  • 결제 및 환불 정책
  • 반품 프로세스
  • 정산 배치 운영 가이드
