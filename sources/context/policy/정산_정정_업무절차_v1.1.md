# 정산 정정 업무절차 (v1.1)

**개정:** 2024-02-19 · **작성:** 정산팀 · **승인:** 재무본부장 · **상태:** 발행

## 1. 목적
정산 완료 이후 발생한 주문 취소 건의 금액 정정 절차와 책임을 정한다.

## 2. 용어

### 2.1 정산 정정
지급이 완료된 정산 금액을 차월 정산에서 차감하여 조정하는 것.

### 2.2 정정 대기 건
취소가 정산 이후에 접수되어 차감이 필요한 상태로 적재된 건.

## 3. 책임

| 구분 | 책임 |
|---|---|
| 정산팀 | 정정 대상 확인, 차월 차감 반영, 파트너 통지 |
| 주문팀 | 취소 이벤트 발행 |
| 재무기획팀 | 분기 결산 시 미정정 잔액 확인 |

## 4. 절차
1. 취소 접수 → 정정 대기 등록 (시스템)
2. 정산팀 확인 (월 1회 이상)
3. 차월 정산 반영
4. 파트너 통지 및 이력 기록

## 5. 기록 및 보존
- 정정 이력은 정산 어드민에 기록하며 5년간 보존한다.
- 월 1회 이상 대기 건 현황을 확인한다. (확인 결과 기록 양식은 아래 참조)
