# [SF-2287] 정산 완료 주문 취소 차단 해제

## 설명

현재 `order-service`는 정산이 완료된 주문에 대해 취소 API 호출 시 409를
반환하고 있습니다. 정책상 의도된 동작이지만, 실무에서 문제가 발생하고 있습니다.

CS팀 기준 3월 한 달간 관련 문의 **214건**이 접수되었습니다. 대부분은 고객이
정당한 사유(오배송, 상품 하자, 주문 착오)로 취소를 요청했으나 정산 배치가
이미 실행되어 차단된 케이스입니다.

고객 입장에서는 "어제 주문했는데 왜 취소가 안 되냐"는 것이고, 실제로 정산
배치는 새벽 2시에 돌기 때문에 **주문 다음날 오전이면 이미 차단**됩니다.
반품 프로세스로 안내하면 처리 기간이 7~10일로 늘어나 컴플레인이 재차
발생합니다.

## 요청 사항

취소 API에서 정산 상태 확인 로직을 제거해 주세요.
