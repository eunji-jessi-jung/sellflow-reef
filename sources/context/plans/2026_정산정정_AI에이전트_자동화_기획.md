# 정산 정정 업무 AI 에이전트 자동화 기획(안)

## 1. 배경

전사 AX 로드맵(2026)에 따라 반복 사무 업무의 에이전트 자동화를 추진 중이다.
정산팀의 **정산 오류 수기 정정** 업무는 다음 이유로 1차 대상으로 선정되었다.

- 규칙이 명확하고 예외가 적음
- 처리 건수가 꾸준함
- 담당 인원이 3명으로 병목 발생 가능성

## 2. 현행 프로세스 (As-Is)

정산 완료 이후 주문이 취소되는 경우, 정산팀이 해당 건을 확인하여
차월 정산에서 차감하는 방식으로 수기 정정하고 있다.

```
주문 취소 발생
  → 정산 정정 대기열 적재
  → 정산팀 담당자 확인
  → 차월 정산 차감 반영
  → 처리 완료
```

근거: SF-2287 (2023-04) 협의 내용, 조직도상 정산팀 담당 프로세스

> 📌 현행 처리량은 정산팀 확인 결과 **월 10건 내외**로 파악된다.

## 3. 목표 (To-Be)

- 대기열 적재 건을 에이전트가 자동 판정하여 차감 처리
- 담당자는 예외 건만 검토
- 목표: 수기 처리 시간 80% 절감

## 4. 선결 과제

- [ ] 현행 처리 규칙 문서화 (정산팀)
- [ ] 대기열 스키마 및 상태 전이 정의
- [ ] 예외 판정 기준 수립
- [ ] 외부 컨설팅 착수 (AX 파트너)

## 5. 일정(안)

| 단계 | 기간 |
|------|------|
| 현행 분석 | 2026-09 |
| 설계 | 2026-10 |
| 개발 | 2026-11 ~ 12 |
| 시범 운영 | 2027-01 |

## 6. 비고

정산팀 인원 조정(2024-07, 4명→3명) 이후 업무 부담이 증가했다는 의견이 있어
자동화 우선순위를 상향 조정하였다.
